# UI 规范

本文件只约束**看得见的**视觉、布局、交互和数据展示。

## 1. 工程与设计体系

- 默认视觉基线即本文件色板、字体、圆角、间距和状态色；目标工程已使用设计 Token 时，色值通过项目 Token 表达，不硬编码新色。
- 品牌字体、固定业务指标色和特定量纲精度等项目约定由项目 Harness 的 `.harness/projectContext/frontend-stack.md` 声明；存在时读取并遵循，与本文件默认值冲突时以项目声明为准。
- 已知目标工程或设计体系时，复用其已安装的组件、图标和 Token，不另起平行视觉体系。
- `static-page` 使用 UI 已确认的组件和 Token；没有正式设计体系时，以下列基础视觉基线为最小基线并在交付证据中说明。
- 公共样式覆盖必须限制在当前页面或组件作用域；新增品牌色、业务色或重复视觉能力前先判断是否应沉淀为 Token。

### 基础视觉基线

- 设计基准为 `1440 × 800`，桌面端优先。
- 正文字体优先 `PingFang SC`，兜底 `Microsoft YaHei` 和系统无衬线字体。
- 品牌特殊字体按项目声明使用，兜底 `PingFang SC`。
- 字号保持固定，不使用 `vw`、`vh` 缩放字体。
- 页面大间距优先 20px，卡片内边距优先 16px，文字/图标/小标签间隙优先 10px，按钮间距优先 8px。避免非倍数的零散间距。
- 基础组件圆角 6px，业务卡片可用 6px / 8px / 10px，不超过 10px。
- 顶部导航阴影 `0 4px 4px rgba(15, 74, 152, 0.04)`；内容卡片阴影 `0 2px 8px rgba(21, 31, 42, 0.15)`。
- 用清晰层级表达标题、筛选、内容、操作和反馈，不用装饰性元素代替信息结构。
- 至少表达正常、加载、空态、失败和适用的禁用状态。

## 2. 布局与响应式

- 横向尺寸和间距可使用 `vw` 适配，纵向可使用 `vh`；字体不随视口缩放。
- 全屏区域使用 `calc(100vh - header)`、`100dvh` 或明确最大宽高约束。
- 固定功能组件避免因 hover、加载或文本溢出产生布局抖动。
- 查询区与表格、卡片或图表共存时，关键操作区仍须保持可见。
- 使用目标工程既有断点；移动端只在业务要求时补充。



## 3. 组件与交互

- 页面、表单、弹窗、抽屉、表格、分页、标签和空状态优先复用目标工程或项目设计体系的既有组件。
- 主按钮使用主题主色底色和白色文字，覆盖常态、hover、active；次按钮使用白底、基础边框和次级文字色。
- 功能和常用操作图标使用描边风格，次要辅助和状态展示图标使用面性风格。图标颜色沿用主题色、辅助文字色或功能状态色。
- 图标使用当前设计体系或项目既有兼容层，按需引入并继承 `currentColor`。
- 一个操作区域最多一个主按钮；破坏性操作使用危险样式和必要确认。
- 异步操作显示 loading 或禁用，防止重复提交。
- 纯图标按钮必须具有可访问名称；必要短说明使用 Tooltip。
- Tooltip 只承载短文本或必要说明，不承载复杂表单、操作区或大段结构化内容。
- 无权限时不展示对应操作入口；不得用可见但禁用的按钮代替权限隐藏，除非邻近页面已有同类可见模式。



## 4. 表单、表格与图表

- 表单的标签、校验、只读、禁用和按钮区与相邻页面一致。
- 表格预先明确列宽、固定列和滚动；数据多时由表体滚动，分页区域必须保持可见，不得让表格撑高整页。
- 长文本使用省略；仅当内容对用户有实际查看价值时提供 Tooltip。
- 默认空值占位为 `-`。产品 Mock 新方案使用 `-`；已有方案若使用 `--` 则保持该方案内统一，同一页面不得混用。
- 图表保持统一色板、轴格式和 Tooltip；坐标轴标签不得相互覆盖。
- 图表无数据时显示 Empty，不保留空白画布，也不展示误导性的全 0 图形。
- 固定业务指标色由项目在 `frontend-stack.md` 中声明并按其使用；不得凭字段名另配一套。




## 5. 数据展示

- 同类数字在表格、图表、详情和导出预览中使用同一格式。
- 无明确业务约定时，普通数值默认保留两位小数；特定单位或字段的精度由项目声明。
- `0` 是有效值，必须按数字展示，不得显示为空值占位。
- 数字默认使用千分位。日期无约定时新增展示使用 `YYYY-MM-DD HH:mm:ss`。同类日期字段在表格、Tooltip、详情和导出预览中保持一致。
- 枚举文案、状态颜色和标签必须来自已确认口径，不得凭字段名猜测。
- 页面级空状态使用大尺寸，组件内使用小尺寸，默认文案为“暂无数据”。
- 列表、表格、图表、详情和搜索结果须覆盖适用的加载、空、失败和权限不足状态；空态不得留下空白错位，也不得直接显示 `null`、`undefined` 或 `NaN`。
