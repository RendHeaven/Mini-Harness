# 历史产品文档

新归档的历史知识按版本存放在 `<版本号>/` 目录：PRD 为 `<版本号>/<版本号>-prd.md`，测试用例为 `<版本号>/<版本号>-测试用例.md`，图片等附件与正文同目录保存。

已有扁平目录中的 `<版本号>-prd.md`、`<版本号>-prd.docx` 和 `<版本号>-prd.pdf` 均可作为历史回溯来源；新版本的 Word 导出不是默认历史事实源。

多产品线项目在上述结构外增加 `<产品线>/` 分区，保持各产品线自身的版本文档与引用；同名文件不允许跨产品线冒充历史来源。纯版本与产品线周期混用时，纯版本周期的历史扫描排除由同级产品线周期声明的历史分区，其余旧结构继续有效。


项目共享原型和跨产品线历史来源按 Core `rules/project-assets.md` 的可选 `asset-registry.yaml` 协议显式登记。读取真实来源并验证消费周期、精确路径和摘要；未登记目录、缺失 Manifest 与未经登记的跨线来源继续报错，不自动生成放行项。
